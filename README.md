# Tensura Capital: Monsters

The Monsters faction capital - the Black Keep in the dark forests and swamps
- for use with the Tensura Faction Spawn ecosystem.

## What it does

Registers the Monsters capital. Once registered, the spawn mod picks it up
automatically: a player who first picks (or reincarnates into) one of the
night races is placed at the nearest registered capital to the world spawn,
and may return to it at will.

- **Monsters** - a deepslate-and-blackstone keep with crying-obsidian veins
  and gold hoard trim, raised in the dark forests and swamps.

Install like any mod, alongside Tensura Faction Spawn.

## Dependencies

| | Mod | Why |
|---|---|---|
| Required | Minecraft | - |
| Required | NeoForge | - |
| Required | Tensura Faction Spawn | Owns the central capital tags and arrival behaviour |
| Required | Tensura: Reincarnated | Owns the night races the capital serves |
